# OCI Advanced Networking: Tenancy Workshop

This workshop is a tenancy-only companion to the broader `oci-advanced-networking` workshop already in this repository. It focuses on a progressive DRG routing story with three small compute instances and a reusable HTTP metadata endpoint.
